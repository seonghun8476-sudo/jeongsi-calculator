1 GitHub Pages 개인정보처리방침 배포

~5분 필수

GitHub 레포지토리 설정

  1. GitHub에 jeongsi-calculator 레포 생성 (이미 있으면 스킵)
    GitHub 새 레포 만들기
  2. 로컬에서 push:
    cd ~/jeongsi-calculator
    git remote add origin https://github.com/YOUR_USERNAME/jeongsi-calculator.git
    git push -u origin main
  3. GitHub 레포 > Settings > Pages
    GitHub 열기
  4. Source를 "Deploy from a branch" 선택
  5. Branch: main, Folder: /docs 선택 > Save
  6. 1~2분 후 URL 확인: https://YOUR_USERNAME.github.io/jeongsi-calculator/
이 URL을 App Store Connect와 Play Console의 개인정보처리방침 URL에 입력합니다.

2 RevenueCat 설정

~30분 필수

2-1. RevenueCat 계정 & 프로젝트 생성

  1. RevenueCat 가입하기
  2. 로그인 후 "Create New Project" 클릭
  3. 프로젝트 이름: 어대갈까

2-2. Apple App Store 연결

  1. RevenueCat 프로젝트 > Apps > + New App > App Store
  2. App Name: 어대갈까
  3. Bundle ID: com.thinkoutsidethebox.jeongsicalculator
  4. App Store Connect Shared Secret 입력:
    App Store Connect 열기
    앱 > 일반 > 앱 정보 > App-Specific Shared Secret > Generate

2-3. Google Play Store 연결

  1. RevenueCat 프로젝트 > Apps > + New App > Play Store
  2. Package Name: com.thinkoutsidethebox.jeongsicalculator
  3. Service Account JSON 업로드 (Step 4에서 생성)
    Play Console 열기

2-4. 상품(Entitlement) 설정

  1. RevenueCat > Entitlements > + New
  2. Identifier: premium
  3. Offerings > default > 패키지 2개 추가:
    • $rc_monthly - 월간 구독 상품 연결
    • $rc_annual - 연간 구독 상품 연결

2-5. API Key를 코드에 적용

  1. RevenueCat > 프로젝트 > API Keys
  2. Public app-specific API keys 복사 (iOS용, Android용 각각)
  3. 파일 수정: lib/purchases.ts
    // 21~22번째 줄의 test_ 키를 교체
    const REVENUECAT_IOS_KEY = 'appl_실제키여기에붙여넣기';
    const REVENUECAT_ANDROID_KEY = 'goog_실제키여기에붙여넣기';
현재 test_ 키가 들어있습니다. 반드시 프로덕션 키로 교체해야 합니다.

3 App Store Connect 구독 상품 등록

~1시간 필수 (iOS)

3-1. 앱 등록

  1. App Store Connect 열기
  2. "+" > New App
  3. Platform: iOS
  4. Name: 어대갈까
  5. Bundle ID: com.thinkoutsidethebox.jeongsicalculator
  6. SKU: jeongsicalculator
  7. Primary Language: Korean

3-2. 인앱 구독 상품 생성

  1. 앱 페이지 > 좌측 Subscriptions
  2. Subscription Group 생성: premium_group
  3. 상품 1 - 월간:

    • Product ID: premium_monthly
    • Duration: 1 Month
    • Price: 4,900원 (Tier 5)
    • 구독 표시 이름: 프리미엄 월간
  4. 상품 2 - 연간:
    • Reference Name: Premium Yearly
    • Product ID: premium_yearly
    • Duration: 1 Year
    • Price: 39,000원 (Tier 39)
    • 구독 표시 이름: 프리미엄 연간

3-3. 앱 정보 입력

  1. App Information:
    • Category: Education
    • 개인정보처리방침 URL: GitHub Pages URL 입력
  2. Pricing and Availability: Free
  3. App Review Information:
    • 연락처: seonghun8476@gmail.com
    • Review Notes: "수능 점수를 입력하면 정시 지원 가능 대학을 보여주는 교육용 앱입니다"

4 Google Play Console 설정

~1시간 필수 (Android)

4-1. 앱 등록

  1. Play Console 열기
  2. Create app
  3. App name: 어대갈까 - 정시 대학 계산기
  4. Default language: Korean
  5. App / Game: App
  6. Free / Paid: Free
  7. Declaration 체크 후 Create

4-2. Google Service Account 생성 (자동 배포용)

  1. Google Cloud Console 열기
  2. 프로젝트 선택 (Play Console과 연결된 프로젝트)
  3. + CREATE SERVICE ACCOUNT
  4. Name: eas-submit
  5. Role: 안 줘도 됨 (Skip)
  6. 생성된 계정 클릭 > Keys > Add Key > JSON
  7. 다운로드된 JSON 파일을 프로젝트 루트에 저장:
    mv ~/Downloads/service-account-*.json ~/jeongsi-calculator/google-service-account.json
  8. Play Console > Settings > API access > 서비스 계정 연결
    API Access 설정
  9. 서비스 계정에 "Admin (all permissions)" 부여
google-service-account.json은 .gitignore에 추가하세요! 절대 GitHub에 올리면 안 됩니다.

4-3. 구독 상품 등록

  1. Play Console > 앱 > Monetize > Subscriptions
  2. Create subscription
  3. 상품 1 - 월간:
    • Product ID: premium_monthly
    • Name: 프리미엄 월간
    • Base plan 추가: 1 Month, 4,900원
  4. 상품 2 - 연간:
    • Product ID: premium_yearly
    • Name: 프리미엄 연간
    • Base plan 추가: 1 Year, 39,000원
  5. Activate

4-4. 스토어 등록 정보

  1. Main store listing:
    • App name: 어대갈까 - 정시 대학 계산기
    • Short description: 수능 점수로 합격 가능 대학을 알려드립니다
    • Full description: store-listing.md 내용 복사
  2. Content rating 설문 완료
  3. Target audience: 18세 이상
  4. Data safety: 개인정보 수집 항목 입력

6 EAS Build & Submit

~30분 필수

6-1. EAS CLI 설치 & 로그인

npm install -g eas-cli
eas login
Expo 계정 만들기

6-2. iOS 빌드 & 제출

# 프로덕션 빌드 (Apple Developer 계정 필요)
eas build --platform ios --profile production

# 빌드 완료 후 App Store Connect에 제출
eas submit --platform ios --latest
Apple Developer Program 가입 필요 ($99/년)
developer.apple.com/programs

6-3. Android 빌드 & 제출

# 프로덕션 빌드 (AAB)
eas build --platform android --profile production

# 빌드 완료 후 Play Store에 제출
eas submit --platform android --latest
Google Play Developer 등록 필요 ($25 일회성)
play.google.com/console/signup

6-4. 스토어 심사 제출

  1. App Store Connect:
    • 앱 > Version > 스크린샷 업로드
    • 앱 설명, 키워드 입력
    • "Submit for Review"
    • 심사 기간: 보통 1~3일
  2. Play Console:
    • 앱 > Production > Create new release
    • AAB 업로드 (EAS submit으로 이미 됨)
    • Release notes: "정시 대학 계산기 첫 출시"
    • "Start rollout to Production"
    • 심사 기간: 보통 1~7일 (첫 앱은 더 오래 걸릴 수 있음)
